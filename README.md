# دانلودکننده اسناد historydocuments.org

ابزاری برای استخراج متن و تصاویر اسناد از سایت [مرکز بررسی اسناد تاریخی](https://historydocuments.org) و ذخیره‌ی آن‌ها به صورت فایل PDF فارسی (راست‌چین).

این اسکریپت متن سند را دقیقاً به ترتیب اصلی استخراج می‌کند، تصاویر را دانلود کرده و به PDF می‌چسباند، و نام فایل را به‌طور خودکار از عنوان سند می‌سازد.

---

## امکانات

- 📄 استخراج متن فارسی با حفظ ترتیب و خطوط (راست‌چین، فونت Amiri)
- 🖼️ دانلود خودکار تصاویر و افزودن آن‌ها به PDF
- 📚 **حالت کتاب**: دانلود همه‌ی اسناد یک کتاب به ترتیب، با پیمایش خودکار همه‌ی صفحات
- 🔁 تلاش مجدد (retry) خودکار برای لینک‌های ناموفق
- 📝 ذخیره‌ی لیست دانلودهای ناموفق در `_failed.tsv` و امکان اجرای مجدد فقط روی آن‌ها
- 🗂️ ذخیره‌ی هر کتاب در پوشه‌ی جداگانه
- 🔓 نادیده‌گرفتن خطای SSL منقضی‌شده‌ی سایت

---

## نصب

به Python 3.9 یا بالاتر نیاز دارید.

```bash
git clone https://github.com/yousefalami/historydocumentsdownloader.git
cd historydocumentsdownloader
pip install -r requirements.txt
```

> فونت `Amiri-Regular.ttf` همراه پروژه است. اگر آن را حذف کنید، اسکریپت در اولین اجرا خودش آن را دانلود می‌کند.

---

## اجرا

```bash
python scraper.py
```

سپس یکی از حالت‌ها را انتخاب کنید:
(پیشنهاد میکنیم حالت 3 استفاده کنین)
| حالت | توضیح |
|------|-------|
| **1** | دانلود یک سند تکی |
| **2** | دانلود یک سند و دنبال‌کردن همه‌ی لینک‌های «صفحه بعد» |
| **3** | دانلود کامل یک کتاب (همه‌ی صفحات و اسناد به ترتیب) |
| **4** | تلاش مجدد روی دانلودهای ناموفق از `_failed.tsv` |

پس از دادن لینک، اسکریپت **فونت** و **اندازه‌ی فونت** را می‌پرسد:

- فونت: `Amiri` (پیش‌فرض) یا `XB Niloofar` — با Enter پیش‌فرض انتخاب می‌شود.
- اندازه: عددی بین ۶ تا ۴۰ (پیش‌فرض ۱۰) — با Enter پیش‌فرض می‌ماند. عنوان و تیترها به‌طور خودکار بزرگ‌تر از این مقدار می‌شوند.

### مثال — دانلود یک سند

```
Mode [1/2/3/4]: 1
URL: https://historydocuments.org/sanad/?page=show_document&id=777emkv1rascs
```

### مثال — دانلود یک کتاب کامل

```
Mode [1/2/3/4]: 3
URL: https://historydocuments.org/sanad/?page=books_doc&id=159
```

اسکریپت تمام صفحات کتاب را (با افزایش پارامتر `start`) پیمایش می‌کند تا به پایان کتاب برسد.

### مثال — تلاش مجدد روی ناموفق‌ها

```
Mode [1/2/3/4]: 4
Path to _failed.tsv [downloads/_failed.tsv]: 
```

---

## خروجی

همه‌ی فایل‌های PDF در پوشه‌ی `downloads/` ذخیره می‌شوند:

- در حالت کتاب، هر کتاب در زیرپوشه‌ی جداگانه با نام خودش قرار می‌گیرد.
- نام فایل‌ها با پیشوند شماره‌ی ترتیبی است (مثل `001 مقدمه.pdf`) تا ترتیب حفظ شود.
- لینک‌های ناموفق در `downloads/_failed.tsv` ثبت می‌شوند.
